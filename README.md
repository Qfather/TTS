# 🎧 TTS 音频库

本地 TTS 音频库 WebUI：管理、分类、筛选、播放 TTS 音频片段。

## 快速开始

```bat
:: 方式一：双击
start.bat

:: 方式二：命令行
pip install flask
python app.py
```

启动后浏览器自动打开 `http://127.0.0.1:5000`。

## 功能

- **单个添加**：名称、来源、性别、年龄、职业、其他标签（逗号分隔多值）、头像（可选，不传用默认头像）、音频文件
- **批量添加**：选择文件夹，每个子文件夹视为一个条目（内含音频文件 + 文件名含 `icon` 的图片作为头像），导入前可逐条修改名称与标签
- **编辑 / 删除**：卡片右上角操作；编辑可改分类与标签、替换头像/音频、移除头像；改分类会自动把文件夹搬到新位置
- **替换音频 API**：`POST /api/items/<id>/audio`（multipart 字段 `audio`），为后续批量替换预留
- **筛选**：来源 / 性别 / 年龄 / 职业 / 其他标签 五行组合筛选（其他标签多选，命中任一即显示）
- **枚举管理**：来源、性别、年龄、职业均为枚举，界面内可随时新增，不卡死
- **播放**：卡片内播放/暂停、进度条拖动、时间显示

## 数据目录结构

```
library/
├── enums.json                  # 枚举：sources / genders / ages / occupations
└── <来源>/<性别>/<年龄>/<职业>/<条目名>/
    ├── meta.json               # 条目元数据（id、名称、分类、tags）
    ├── audio.mp3               # 音频文件（任意格式）
    └── icon.png                # 头像（文件名含 icon 的图片，可选）
```

> 直接往 `library/` 里按上述结构放文件夹也能被自动扫描识别（`meta.json` 缺失时该目录会被跳过，可先通过界面添加后再手工补文件）。

## 技术栈

- 后端：Python + Flask（单文件 `app.py`，无数据库，数据即目录结构）
- 前端：原生 HTML/CSS/JS 单页（`static/`）
